# My Movie List

## Description
My Movie List is a React web application that allows users to organize and manage their favourite movies.

## Features
- Add new movies with title, genre and release year.
- Edit existing movie details.
- Delete movies.
- Search movies by title.
- Filter movies by genre.
- View total and displayed movie counts.
- Save movies using Local Storage.

## Technologies Used
- React
- JavaScript
- HTML
- CSS
- Vite
- Github pages
- Vercel
## Installation
1. Clone the repository.
https://github.com/thomaskamau7588-star/-react-movie-list
2. Open the project folder in VS Code.
3. Run `npm install` to install dependencies.
4. Run `npm run dev` to start the application.
